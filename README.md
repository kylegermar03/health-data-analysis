# health-data-analysis
# Global Health Trends Analysis 
An end-to-end data analysis project using WHO life expectancy data across 193 countries from 2000 to 2015.

## Tools Used
 **Python** (pandas, matplotlib, numpy) - data cleaning and visualization
 **SQL** (SQlite) - data aggregation and querying
 **Tablaeu Public** - interactive dashboard

 #Key Findings
- Global average life expectancy rose from 67 to 72 years between 2000 and 2015
- Developed countries average 79.2 years vs 67.1 years for developing countries — a 12-year gap
- Higher GDP strongly correlates with longer life expectancy, with diminishing returns at higher income levels
- Identified and corrected data quality issues, including misclassified country status values
